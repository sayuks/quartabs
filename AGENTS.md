## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (`sayuks/quartabs`) via the `gh` CLI. See `dev/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `dev/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` plus ADRs in `dev/adr/` (not `docs/adr/`: `docs/` is git-ignored altdoc output). See `dev/agents/domain.md`.
